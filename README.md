# Görlitz666 – Installer

Hier liegen nur die fertigen Installer von **Görlitz666** (Quill · Grid · Pulse) für Windows. Der Quellcode ist privat.

## Installieren
1. Unter [Releases](../../releases/latest) die Datei `Goerlitz666-Setup-x.y.z.exe` herunterladen und ausführen.
2. Windows zeigt eine SmartScreen-Warnung, weil der Installer nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.
3. Im Startmenü und auf dem Desktop gibt es danach **Görlitz666 Quill**, **Görlitz666 Grid** und **Görlitz666 Pulse**.

## Updates
Görlitz666 prüft automatisch alle 4 Stunden, ob es hier eine neue Version gibt, lädt sie im Hintergrund und installiert sie beim Beenden. Ein Token ist dafür nicht nötig.

## KI-Funktionen
Für Claude in Quill, Grid und Pulse wird ein eigener Claude-API-Schlüssel benötigt (Pulse → Einstellungen → KI). Die betroffenen Texte werden dafür an Anthropic gesendet – bitte die Richtlinien des Arbeitgebers beachten.
